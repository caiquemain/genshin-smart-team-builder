# Genshin Smart Team Builder & Resource Calculator

Plataforma web para planejamento estrategico de times, guias visuais e calculo preditivo de recursos em Genshin Impact.

Projeto extensionista - UNINASSAU / Ciencia de Dados.

## Stack
- Backend: FastAPI + SQLAlchemy + PostgreSQL
- Frontend: React (proxima etapa)
- Infra: Docker + Docker Compose
